# 1.3.0.bata2 · Electron 界面重写测试版

本版为 Windows x64 预发布版本，仅提供免安装 ZIP，使用独立测试更新渠道；稳定版入口继续保留。

## 本次更新

- 使用 Vue 3 + TypeScript + Electron 重写桌面界面，保留 Python 抓取、统计、归档与上传核心，以及左侧五页导航。
- 保留抓取与进程选择、服务器识别、UID 校验、多账号、导入导出与拖放、备份、资源补全、上传和绑定等功能。延续账号隔离、迁移保留原文件和并发写档保护。
- 界面统一为白、黑两种主题，首次默认白色；旧星轨主题映射黑色，晴空和手札映射白色。选择可记忆，切换时保留输入与筛选。
- 招募记录改为紧凑的纵向卡池历史，突出本池累计抽数，增加头像与五星间隔条。色条使用同页统一刻度，保留 UP、歪和兑换奖励标记，奖励不计入抽数与五星统计。
- 补齐页面、导航、卡片、弹窗、更新步骤与任务面板的过渡动画，并遵循系统“减少动态效果”设置。
- 移除今日运势，保留五星概率、平均抽数、垫抽等客观统计。
- 更新界面加入可滚动说明、下载百分比、大小、速度、预计剩余时间、后台下载、取消、重试和稍后安装。重新启动后重新核验 SHA-256；安装前等待相关进程退出，保留归档、配置保护和替换失败回滚。
- 新增底部任务与日志面板及后台断线重连，日志隐藏上传地址与归档原文。记录由 Python 筛选与分页，已验证十万条记录的分页和搜索。
- ZIP 自带 Electron 和独立 Python 核心，无需安装 Python，不携带 PySide6 界面运行库。继续附带 MIT 许可证、来源署名及第三方许可。

## 下载与升级

下载 `StellaSoraGachaTool-1.3.0.bata2-win64.zip`，完整解压后运行 `StellaSoraGachaTool.exe`，启动时按提示授予管理员权限。`StellaSoraUpdater.exe` 仅供主程序调用。

**升级前备份整个 `exports`。** 使用新目录解压时，将旧版完整 `exports` 复制到新版程序旁；保留 `<UID>.json`、账号配置、备份和旧档。请完整解压程序，不要只替换单个 EXE。旧 Qt 版可在历史 Release 下载。

## 验证与范围

- Python 核心与接口测试、Vue 组件测试、Electron 端到端操作以及十万条记录测试通过。
- 验证了中文与空格路径、无 Python/Node 环境、生产管理员清单、许可文件和运行数据排除。
- 验证了更新取消、网络失败重试、哈希错误、稍后安装恢复和文件替换失败回滚；网络异常由测试替身复现。
- 本次没有执行真实游戏客户端的内存抓取或真实对外上传，相关核心逻辑及其既有测试继续保留。

版本名称沿用维护者指定的 `bata` 拼写；Python 元数据为 `1.3.0b2`，Electron 元数据为 `1.3.0-beta.2`。
