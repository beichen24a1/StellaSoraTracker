# 1.3.0.bata4 · 活动池统计与更新权限修复

Windows x64 预发布版本，继续只提供免安装 ZIP，测试更新渠道升级到 b4。

## 本次更新

- 修复周年特选（原始分类 6、Gid 1001）混入常规限时卡池的问题。四张常规卡的抽数、五星、垫抽和 UP 平均单独计算，活动池记录继续可查看、筛选；账号累计仍包含活动池，归档与分享格式不变。
- 修复旧更新器遗留的受保护程序权限，临时更新目录恢复继承，安装后再次校验程序文件权限。
- 遇到 `WinError 740` 时请求 Windows 管理员授权重启主程序，保留失败回滚与下载包保护。
- 收窄旧安装权限修复范围：只处理本次更新包管理的损坏程序条目，不重置安装目录自身、用户数据、健康文件或无关目录的自定义权限。
- 跳过符号链接、junction 等 reparse point 所在条目的自动权限修复，避免修改链接目标的数据权限。
- 保留 b3 的完整功能、白黑主题、好感度、更新进度、稍后安装、账号隔离、备份和上传保护。
- 构建和开发预览入口显式准备 Electron 运行时，避免干净安装依赖后因缺少二进制无法打包或启动。

## 下载与升级

下载 `StellaSoraGachaTool-1.3.0.bata4-win64.zip`，完整解压后运行 `StellaSoraGachaTool.exe`，按 Windows 提示确认管理员授权。无需安装 Python，不提供独立安装向导。

升级前备份整个 `exports`。若旧版本更新后无法访问或无法启动，将完整 ZIP 解压到有写权限的新目录，再复制旧版完整 `exports`，不要只替换单个 EXE。

已撤下的 `1.3.2`、`1.3.3.bata1` 数字高于本版，自动检查不会将 b4 识别为新版，需要使用新目录手动迁移。更早客户端第一次升级仍可能执行自己的旧更新器；本版不能改写仍在运行的旧客户端代码。
