# 1.3.0.bata5 · 主页、活动日历与自定义弹窗

Windows x64 预发布版本，继续只提供免安装 ZIP。测试更新渠道升级到 b5，稳定更新渠道保持原样。

## 本次更新

- 新增默认主页，汇总当前账号的招募统计、近期五星、角色、好感度及活动日程，提供各功能入口；原招募总览保留为独立页面。
- 新增国服活动日历，展示主视觉、常驻活动、日程范围筛选、倒计时和官网公告；支持手动刷新与离线缓存，时间按北京时间显示。
- 新增角色数据页，读取等级、突破、技能、天赋、纹章及潜能，按 UID 独立缓存；修复切换账号后显示旧数据、无缓存账号借用其他账号数据、迟到请求覆盖当前账号及异常缓存问题。
- 普通提示、账号管理、游戏进程选择、更新、取消下载、角色/纹章详情及任务日志统一为白黑两套应用内设计。文件和文件夹选择器、系统管理员授权保留原样。
- 退出确认改为应用内弹窗，重复关闭不会叠窗，停止下载并退出前再次检查是否正在保存数据。
- 启动异常提供独立恢复页，支持重试、复制详情和打开日志；更新器提供不依赖 Electron/Qt/Tcl 的自绘故障窗口，从隐藏后台启动时也能显示。
- 保留既有招募抓取、导入导出、多账号、UID 校验、活动池分类、备份、上传及更新回滚保护。

## 下载与升级

下载 `StellaSoraGachaTool-1.3.0.bata5-win64.zip`，完整解压后运行 `StellaSoraGachaTool.exe`，按 Windows 提示确认管理员授权。无需安装 Python，不提供安装向导。

升级前备份整个 `exports`。如旧程序无法更新或启动，请完整解压 ZIP 到新目录，再复制旧版整个 `exports`，不要只替换单个 EXE。已撤下的 `1.3.2`、`1.3.3.bata1` 数字高于本版，需使用新目录手动迁移。

活动日历仅提供国服官网日程，不随当前游戏服务器切换；信息与奖励以官方公告及游戏内为准。主页仅读取已保存的摘要，不自动读取游戏或上传数据。

版本名称保留 `bata` 拼写；Python 元数据为 `1.3.0b5`，Electron 元数据为 `1.3.0-beta.5`。随包附带 MIT、来源署名和第三方许可。
