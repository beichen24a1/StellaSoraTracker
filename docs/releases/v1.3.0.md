# v1.3.0 · 双仓库功能整合版

整合 sfjdk/StellaSoraTracker 与 zhenkotone/stellasora_gacha，保留双方提交历史，并按人工判断清单落实功能取舍。

- 保留三套主题、左侧导航、多账号、JSON/CSV 与拖放导入、搜索和全部抽卡浏览；新增卡池一列/两列选择与记忆，修复手动备份入口。
- 周年特选招募使用原始分类 `6`，独立统计和保底；普通旅人限时池的 120 抽奖励仅参与展示，不增加真实抽数或五星统计。区分首页 UP 保底进度与记录页五星间隔。
- 多开时按进程名、PID、路径选择；读取前后核验唯一 UID 与进程启动时间，切号或 UID 异常时阻断保存；保存和上传前检查跨账号异常重复记录。
- 自动上传默认关闭，保留指纹去重和手动上传。上传成功表示暂存，每次仍需向蕾姆发送绑定指令确认；客户端保留分类 `6`，服务端兼容性需要单独确认。
- 自动更新默认开启，启动检查，下载前询问，SHA-256 校验后再确认安装；不再每 6 小时检查。更新清单与下载资产统一指向本仓库。移除公开的 `--demo` / `--beta` 演示入口。

下载 `StellaSoraGachaTool-1.3.0-win64.zip`，**完整解压**后运行 `StellaSoraGachaTool.exe`，无需安装 Python。读取游戏时按提示授予管理员权限，先在游戏内打开需要抓取的招募记录。更换账号后请完全退出并重启游戏。

升级前备份整个旧 `exports`。从 sfjdk 版升级，可复制完整 `exports` 到新版程序旁；从 zhenkotone 版升级，在「数据与设置」导入原 `<UID>.json`，或拖入窗口，保留原文件。无 UID 或损坏旧档不会自动认领、覆盖。

提供 `SHA256SUMS.txt` 核验下载文件。463 项自动测试通过；发行包已验证三主题/五页面启动、中文路径重定位、资源一致性、升级保留账号/归档/偏好及防串号会话标记。游戏内读取与线上上传未进行实机联调，台服适配目前依据模拟内存测试。
