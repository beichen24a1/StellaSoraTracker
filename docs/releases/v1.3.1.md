# v1.3.1 · UID 读取与卡池归类修复

本次更新集中修复国服实机读取问题，并整理卡池与上传入口。

- 修复 UID 读取失败：优先使用游戏内玩家表 / UID 标签里的 UID；`nUid` 等内部账号字段只作兜底，避免把内部 ID 当成游戏内 UID。支持 `UID：123`、`UID: 123` 等本地化标签写法。
- 临时读不到 UID、或读取结束复核失败时，不再永久阻断整个游戏会话；只有确认同一次游戏启动中切换了账号才要求重启游戏。旧版本遗留的、没有绑定过 UID 的无效阻断标记会自动清理。
- 周年特选按活动卡池展示，移除单独的「周年特选」分类；归档中仍保留原始分类 `6`，抓取、导入、CSV、合并、分享和上传格式不变。
- 上传到蕾姆的地址固定内置、不在界面显示，也不再读写 `rem_upload_endpoint.txt`；地址在源码中编码保存。
- 优化 UID 扫描：不再对裸 `UID` 做全内存扫描，读取速度恢复；没有活动卡池时「活动卡池」筛选自动隐藏。
- 验证：472 项自动化测试通过；国服实机读取 UID `100872990`、1698 抽 / 744 组记录，GUI 与打包版冒烟测试通过。

下载 `StellaSoraGachaTool-1.3.1-win64.zip`，**完整解压**后运行 `StellaSoraGachaTool.exe`，无需安装 Python。`StellaSoraUpdater.exe` 只由主程序的自动更新流程调用（会先复制到临时目录），请不要手动双击更新器。升级前请备份整个 `exports` 目录；不要只复制单个 exe。
