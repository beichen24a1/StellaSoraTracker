# v1.3.2 · 好感度页与四星头像

本次更新新增「好感度」页，并修正好感经验上限的读取。

- **新增「好感度」页**：左侧导航独立按钮，只读访问游戏内存，列出每位旅人的好感等级、当前经验与升级所需经验（如 `小禾 Lv.65 6040 / 33100`），收藏的角色带星标。
- **数据按 UID 单独存放**：保存为 `exports/<UID>_affinity.json`，与 `exports/<UID>.json` 抽卡归档完全分开，不改动、不混入抽卡数据。读取不到 UID 时写入 `unverified_affinity.json`，不会猜一个 UID 挂上去。页面会显示这份数据对应的 UID 与文件位置。
- **修复部分等级升级经验错误**：游戏里角色升级、秘纹等配置表同样带 `NeedExp` 字段，旧逻辑按"最近的同名字段"配对，会把它们的数值错配到相邻的好感等级上。现在用配置行自身的 `Id` 与 `AffinityLevel` 的一致性校验，只保留对得上的行。
- **补齐四星角色头像**：新增 16 张四星头像（琥珀、缇莉娅、卡西米拉、鸢尾、尘沙、师渺、岭川、璟麟、科洛妮丝、卡娜丝、杏子、紫槿、特丽莎、珂赛特、焦糖、菈露），好感度页四星角色不再只显示首字占位。
- 好感度读取复用本次游戏启动已确认的 UID，同一会话只确认一次；该操作只读，与抓取/上传互不阻塞，游戏没开时页面显示上次保存的结果。
- 清理未使用的导入、样式与构建残留。

验证：530 项 Python 自动化测试通过；前端单元测试与 Electron 端到端（好感度页、四星头像加载、`<UID>_affinity.json` 与抽卡归档分离）通过。
