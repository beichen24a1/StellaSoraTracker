# 1.3.3.bata1 · 普通模式启动器测试版

本版为 Windows x64 预发布版本，仅提供免安装 ZIP，使用独立测试更新渠道；稳定版入口继续保留。

## 本次更新

- **新增普通模式启动器**：双击 `启动器.exe` 即以普通权限启动，不再一开程序就弹 UAC；浏览记录、导入导出、备份、设置和同步资源都可用。
- **按需提权**：普通模式下点「抓取抽卡记录」「读取游戏 UID」「读取好感度」会提示一次，确认后工具以管理员身份重新启动，重启后再点一次刚才的操作即可继续。也可以用 `启动器.exe --admin` 或右键「以管理员身份运行」直接以管理员启动。
- **修复自动更新后主程序无法启动**：更新器以前把文件「移动」进程序目录，会连同更新器临时目录的权限一起搬过去，导致程序文件只剩管理员可读，普通双击在 UAC 之前就被系统拒绝。现在改为复制落地以继承程序目录权限，并在安装后校验每个自带 exe 对普通用户可读可执行，不通过就回滚。
- **清理更新残留**：每次更新开始时清理上次留下的 `stellasora-updater-*`（超过 1 小时）和 `stellasora-update-work-*`（超过 7 天）临时目录，删除失败会先重置权限再重试。
- 主程序清单从 `requireAdministrator` 改为 `asInvoker`；安装包与快捷方式指向 `启动器.exe`；README 增加「启动方式」说明。

## 下载与升级

下载 `StellaSoraGachaTool-1.3.3.bata1-win64.zip`，完整解压后双击 `启动器.exe` 运行（普通模式）。需要读游戏时按提示授权一次即可。`StellaSoraGachaTool.exe` 也可以直接双击，等同普通模式；`StellaSoraUpdater.exe` 仅供主程序调用。

**升级前备份整个 `exports`。** 使用新目录解压时，将旧版完整 `exports` 复制到新版程序旁；保留 `<UID>.json`、账号配置、备份和旧档。请完整解压程序，不要只替换单个 EXE。普通模式需要在程序目录写入 `exports` 和 `.desktop`，请放在自己有写权限的目录，不要放在 `Program Files` 下。

## 验证与范围

- 全量 Python 测试 565 项通过（含旧 Qt 对照界面测试，离屏运行）。
- 验证了：启动器与主程序清单均为 `asInvoker`；冻结引擎在普通模式下对读内存方法返回 `AdminRequired`、`app.state` 正常；打包版普通权限启动可加载界面；更新器复制落地、权限校验与回滚；临时目录清理逻辑。
- 未在真实游戏客户端上执行内存抓取（提权弹窗无法自动化），相关核心逻辑及其既有测试继续保留。

版本名称沿用维护者指定的 `bata` 拼写；Python 元数据为 `1.3.3b1`，Electron 元数据为 `1.3.3-beta.1`。
