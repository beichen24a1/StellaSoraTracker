## v2.0.0

### 🌟 本次亮点

- 【界面】Vue 3 + TypeScript + Electron 桌面界面正式发布，保留 Python 抓取与归档核心，提供白、黑两种主题及切换记忆。
- 【主页】集中展示当前账号的招募统计、近期五星、角色、好感度和活动日程，卡片整块点击即可进入对应页面。招募总览继续独立保留。
- 【更新】提供更新说明、下载进度、速度及剩余时间，支持后台下载、取消、重试、稍后安装和安装后重启。

### ✨ 新增

- 【角色】展示等级、突破、技能、天赋、纹章与潜能，缓存按 UID 隔离。纹章名称前增加真实缩略图，保留属性和词条。
- 【好感度】读取并保存旅人好感度，切换账号后使用各自缓存。
- 【活动】新增国服官网活动日历，展示活动图片、日程筛选、倒计时及公告入口，支持手动刷新和离线缓存，时间按北京时间显示。
- 【上传】新增 hhmx.cn 手动上传及独立自动上传开关；蕾姆上传、绑定指令和原有入口继续保留。两个站点分别授权、分别去重，一个失败不阻断另一个。 (#35) by @sfjdk
- 【协作】新增“从源码启动.cmd”，自动准备项目依赖、构建界面并启动，方便协作者直接运行源码。首次需要安装 Python 3.10+、Node.js 22.12+ 并联网下载依赖。 (#34)

### 🔧 变更

- 【弹窗】账号管理、游戏进程选择、更新、角色详情及任务日志统一使用应用内设计，支持明暗主题和键盘操作；文件、文件夹选择器和 Windows 管理员授权保持系统界面。
- 【记录】保留抓取、服务器识别、多账号、UID 校验、JSON/CSV 导入导出、归档迁移、备份和活动卡池分类，支持分页浏览及列数记忆。
- 【启动】免安装 ZIP 内置 Electron 和 Python 核心，无需安装 Python；解压后运行 StellaSoraGachaTool.exe，启动时确认一次管理员授权。
- 【依赖】Electron 升级至 45.2.1，vue-tsc 升级至 3.3.14，Node.js 类型定义升级至 26.6.6。 (#36, #37, #38) by @dependabot

### 🗑️ 移除

- 【界面】移除旧 Qt 界面运行库、三套旧主题及“今日运势”，保留五星概率、平均抽数等客观统计。
- 【角色】移除纹章背景描述，减少列表冗余。

### 🐛 修复

- 【统计】活动卡池与周年特选单独分类，不再计入秘纹限时统计。
- 【账号】修复角色缓存串号、无缓存账号显示其他账号数据、迟到请求覆盖当前账号和异常缓存问题。
- 【更新】修复更新后程序文件权限异常、主程序无法重启、临时清理失败误报及本地页面加载失败；程序文件按包替换，保留用户数据和自定义目录权限，安装失败支持回滚。
- 【恢复】启动失败提供独立恢复页，可重试、复制详情和打开日志；更新器错误窗口不依赖 Electron、Qt 或 Tcl。
- 【上传】兼容上传站点返回的 error、detail、message 等错误格式，保留可执行的失败提示。 (#35) by @sfjdk

### 🔒 数据与隐私

- 【归档】数据继续保存在程序旁的 exports，保留导入前备份、同 UID 合并、可恢复删除、防串号及并发写档保护。
- 【上传】两个站点的自动上传均默认关闭。开启后会向所选站点发送对应 UID 的完整抽卡归档；蕾姆每次上传后仍需手动发送绑定指令，hhmx.cn 无需绑定指令。
- 【更新】安装前校验 SHA-256，稍后安装的包在重启后重新校验；自动更新可关闭，手动检查保留。

### 下载与升级

只提供 Windows x64 免安装包：`StellaSoraGachaTool-2.0.0-win64.zip`。请完整解压后运行 `StellaSoraGachaTool.exe`，不要单独运行更新器或只替换 EXE。

升级前备份整个 `exports`。稳定与测试更新渠道均可升级到 2.0.0；若旧版无法更新、无法启动，或使用已撤下的 1.3.2 / 1.3.3.bata1，请解压到全新目录，再复制旧版整个 `exports`。历史 b1–b5 保留下载。

活动日历只提供国服官网日程，规则以官方公告与游戏内为准。本次发布为桌面版，Web 页面仍处于独立预览阶段，未包含在发行包中。

### 验证与范围

- 538 项 Python 测试、39 项 Vue 单元测试、9 项源码 Electron E2E 和 1 项冻结包 E2E 通过，前端类型检查和构建通过。
- 使用原始 b5 客户端，在中文及空格路径中实测软件内检查、下载最终发行 ZIP、SHA-256 校验、安装替换和自动重启到 2.0.0；测试归档、账号、原有偏好和用户目录权限保留。
- 冻结包在真实管理员权限和生产沙箱下启动，PATH 不提供 Python 或 Node；包完整性、Windows x64 管理员清单、许可文件、运行数据排除及无 Qt 运行库检查通过。
- 本轮未进行真实游戏抓取或对外上传验收；本机 HTTPS 更新实测不代表所有用户的公网 GitHub 连通性。
