- 【资源】随包补充优叶及两张新秘纹图片，重新生成资源清单、图片哈希与资源包。

### 🔧 变更

- 【依赖】Electron 更新至 45.2.3、Vue 更新至 3.5.45，并更新构建与测试依赖；原有页面布局、明暗主题及归档操作沿用 2.0.0。 (#40, #41, #42, #43) by @dependabot

### 🐛 修复

- 【招募】登记五星旅人 161“优叶”、五星秘纹 214068“帐幕下的酣梦”和 214069“紧急救援”，修复显示为“旅人 / 秘纹 #编号”及因此产生的 UP 名称匹配问题。 (#44) by @sfjdk

- 【维护】按条目实际星级校验，三星、四星名称与五星条目可以在同一批次补全，低星条目不再阻断整批刷新。 (#45) by @sfjdk

### 下载与升级

本版定位为 2.0.0 之后的小版本热修复。稳定与测试更新渠道均可检查到 2.0.1；软件内下载并通过 SHA-256 校验后，选择安装并重启生效。

只提供 Windows x64 免安装包：`StellaSoraGachaTool-2.0.1-win64.zip`。手动升级时请先备份整个 `exports`，完整解压 ZIP 到新目录，复制旧版整个 `exports`，再运行 `StellaSoraGachaTool.exe`。无需安装 Python，启动时按 Windows 提示确认管理员授权。

游戏配置表补名需要游戏已运行且有读取权限；本次只补名称，头像继续使用内置资源或原有联网补全方式。Web 页面仍属于独立预览，未包含在桌面发行包中。
